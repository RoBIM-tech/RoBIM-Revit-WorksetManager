# 1.0.0 정식 배포

기준 TEST: 0.1.0-test.9. Revit VV/VG 스타일의 프로젝트 브라우저 단일 계층 트리-그리드 구조에서 카테고리·패밀리·타입 및 모델 그룹, 룸(SpatialElement), 선(CurveElement) 단위로 작업 세트(Workset)를 체계적으로 조회하고 일괄 지정·수정하는 기능이 검증되었습니다.

- 점선 가이드라인(Continuous dotted lines) 및 9×9 [+/-] 상자 배치로 시각적 계층 구분 완성
- 22px 콤팩트 행 높이 및 VV/VG 밴딩/선택 스타일 적용
- 방향키/PageUp/PageDown/Home/End 및 한글 초성/영문 Type-Ahead 탐색 시 포커스 고정 (작업세트/상태 셀 이탈 방지)
- 트리 접기 시 상위 부모로의 스마트 포커스 유지
- 단일 Undo 기반의 안전한 모델 수정 보장

사용자 gagaggan이 지정한 Revit 2026.5 / 26.5.0.55 환경에서 실기 검증을 완료했습니다.
공용 WPF 및 Common은 공용 정식 0.1.0 버전을 사용합니다.
