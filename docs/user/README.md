# 타입별 작업 세트 관리 - 사용자 설명서

Revit 프로젝트 내 모든 **카테고리, 패밀리, 타입 및 모델 그룹**의 작업 세트(Workset)를 한눈에 조회하고, 원하는 계층 어디서든 편리하게 일괄 지정·수정할 수 있는 도구입니다.

---

## 1. 사전 요구사항
- **작업 공유(Worksharing) 활성화 모델**:
  - 본 도구는 작업 세트(User Workset)를 다루므로, Revit 상단 **[공동 작업(Collaborate)]** 탭에서 작업 공유가 활성화된 모델 문서여야 합니다.
  - 작업 공유가 활성화되지 않은 일반 문서에서 실행 시 안내 메시지가 표시되고 안전하게 종료됩니다.

---

## 2. 화면 구성 및 3단 캐스케이드(Cascade) 설정

화면은 **상단 필터/일괄 지정 툴바**와 **3단 분할 패널(카테고리 ➡️ 패밀리 ➡️ 세부 타입)**, **하단 상태 및 실행 버튼**으로 구성되어 있습니다.

```
+------------------------------------------------------------------------------------------------------------------------------+
| 타입별 작업 세트 관리 · 0.1.0-test.2 · TEST                                                                         _ □ X     |
+------------------------------------------------------------------------------------------------------------------------------+
| 통합 검색: [                    ]  [v] 배치된 인스턴스만 표시 (그룹 포함)         선택 항목 일괄 지정: [ Workset1 ▼ ] [선택 일괄 적용]|
+------------------------------------------------------------------------------------------------------------------------------+
| 🏷️ 카테고리 목록           카테고리 전체 변경 | 📁 패밀리 목록            패밀리 전체 변경 | 📄 세부 타입 목록            타입별 변경 상태  |
| [선택] 카테고리    요소수 [작업세트 드롭다운▼]| [선택] 패밀리명   요소수 [작업세트 드롭다운▼]| [선택] 타입명       요소수 [작업세트 드롭다운▼] |
| [ v ]  문         18     [ Arch_Interior ▼ ] | [ v ]  단일 여닫이 18    [ Arch_Interior ▼ ] | [ v ]  0900 x 2100  10     [ Arch_Interior ▼ ] 동일 |
| [   ]  벽         32     [ 선택 안 함    ▼ ] | [   ]  기본 벽     32    [ 선택 안 함    ▼ ] | [   ]  1000 x 2100   8     [ Arch_Interior ▼ ] ->   |
| [   ]  모델 그룹   4      [ Group_Core    ▼ ] | [   ]  코어 모듈   4     [ Group_Core    ▼ ] | [   ]  타입 1       4     [ Group_Core    ▼ ] 동일 |
+------------------------------------------------------------------------------------------------------------------------------+
| ⚡ 총 1개 카테고리 · 1개 패밀리 · 2개 타입 · 18개 요소 변경 예정                                     [변경 초기화] [적용] [닫기] |
+------------------------------------------------------------------------------------------------------------------------------+
```

### 1) 카테고리 - 패밀리 - 타입 3단계 어디서든 변경 가능
- **1단계: 카테고리 레벨 변경**:
  - 카테고리 행에서 작업 세트를 변경하면, **해당 카테고리에 속한 모든 패밀리와 타입, 배치된 모든 요소**가 한 번에 일괄 동기화됩니다.
- **2단계: 패밀리 레벨 변경**:
  - 특정 패밀리 행에서 작업 세트를 변경하면, **해당 패밀리에 속한 모든 타입과 요소**가 일괄 변경됩니다.
- **3단계: 타입 레벨 개별 변경 (Override)**:
  - 우측 세부 타입 목록에서 특정 타입만 개별 지정하면, 상위 설정보다 **개별 타입 설정이 우선 적용**됩니다.

### 2) 모델 그룹(Model Group) 완벽 지원
- 프로젝트 내의 모델 그룹(`GroupType` 및 `Group` 인스턴스)도 **`모델 그룹 (Model Groups)`** 항목으로 완벽하게 수집 및 표시되며, 그룹 인스턴스의 작업 세트도 편리하게 변경할 수 있습니다.

### 3) Shift / Ctrl 다중 선택 및 스페이스바(Space) 토글
- 마우스 드래그, **`Shift + 클릭` (범위 선택)**, **`Ctrl + 클릭` (추가/제거 다중 선택)**을 완벽 지원합니다.
- 여러 행을 선택한 상태에서 **`Space` (스페이스바)** 키를 누르면 선택된 모든 행의 체크박스가 한 번에 일괄 토글됩니다.
- 여러 행을 파랗게 선택한 뒤 상단 툴바의 **[선택 일괄 적용]**을 누르면 선택된 모든 항목에 지정한 작업 세트가 한 번에 적용됩니다.

### 4) 관용적 수정(Tolerant Bulk Editing) 및 안전 처리
- 모델 수정 시 특정 요소가 잠겨있거나(Pinned), 다른 사용자가 체크아웃 중이거나, 그룹에 종속되어 개별 수정이 불가하더라도 **전체 작업이 취소되지 않고 수정 가능한 요소들은 모두 정상 수정**됩니다.
- 수정 완료 후 건너뛴 요소 수량과 원인을 명확하게 리포트해 드립니다.
- 작업 완료 후 Revit에서 **`Ctrl + Z` (실행 취소)**를 1회 누르면 변경된 모든 요소가 즉시 이전 상태로 안전하게 롤백됩니다.
