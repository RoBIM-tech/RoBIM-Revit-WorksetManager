# 타입별 작업 세트 관리 - 사용자 설명서

Revit 프로젝트 내 모든 패밀리와 타입의 작업 세트(Workset)를 한눈에 조회하고, 패밀리 단위 또는 개별 타입 단위로 편리하게 일괄 지정·수정할 수 있는 도구입니다.

---

## 1. 사전 요구사항
- **작업 공유(Worksharing) 활성화 모델**:
  - 본 도구는 작업 세트(User Workset)를 다루므로, Revit 상단 **[공동 작업(Collaborate)]** 탭에서 작업 공유가 활성화된 모델 문서여야 합니다.
  - 작업 공유가 활성화되지 않은 문서에서 실행 시 안내 메시지가 표시되고 안전하게 종료됩니다.

---

## 2. 화면 구성 및 주요 기능

화면은 **상단 필터/일괄 지정 툴바**, **좌측 패밀리 목록(마스터)**, **우측 세부 타입 목록(디테일)**, **하단 상태 및 실행 버튼**으로 구성되어 있습니다.

```
+-----------------------------------------------------------------------------------------+
| 타입별 작업 세트 관리 · 0.1.0-test.1 · TEST                                    _ □ X     |
+-----------------------------------------------------------------------------------------+
| 카테고리: [ 전체 ▼ ]  검색: [               ]  [v] 배치된 인스턴스만 표시  선택 일괄지정: [ ▼ ] [적용]|
+-----------------------------------------------------------------------------------------+
| [선택] 카테고리   패밀리 이름         타입수 배치수 현재 작업세트 패밀리 전체 변경 작업세트 | [선택] 타입 이름      배치수 현재 작업세트 타입별 변경 작업세트 상태 |
| [ v ]  문        단일 여닫이문        2      18     (혼합)       [ Arch_Interior ▼ ]       | [ v ]  0900 x 2100 mm 10     Workset1      [ Arch_Interior ▼ ] -> |
| [   ]  문        방화문              1      6      Workset1     [ 선택 안 함    ▼ ]       | [   ]  1000 x 2100 mm 8      Arch_Interior [ Arch_Interior ▼ ] 동일 |
+-----------------------------------------------------------------------------------------+
| ⚡ 총 1개 패밀리 · 2개 타입 · 18개 인스턴스 작업 세트 변경 예정       [변경 초기화] [적용] [닫기] |
+-----------------------------------------------------------------------------------------+
```

### 1) 상단 필터 및 일괄 지정 툴바
- **카테고리 필터**: 특정 카테고리(문, 창, 벽, 가구, 기계장비 등)만 필터링합니다.
- **검색창**: 패밀리명 또는 타입명을 실시간으로 검색합니다.
- **배치된 인스턴스만 표시**: 프로젝트에 실제 배치된 요소(`배치수 > 0`)만 빠르게 모아볼 수 있습니다.
- **선택 항목 일괄 지정**: 체크박스로 여러 패밀리나 타입을 선택한 뒤 원하는 작업 세트를 한 번에 일괄 적용합니다.

### 2) 패밀리 단위 변경 (좌측 패널)
- 좌측 그리드에서 원하는 패밀리의 **`패밀리 전체 변경 작업세트`** 드롭다운을 변경하면, **해당 패밀리에 속한 모든 타입과 배치된 모든 요소(인스턴스)의 대상 작업 세트가 한 번에 자동 갱신**됩니다.

### 3) 개별 타입 단위 변경 (우측 패널)
- 좌측에서 패밀리를 클릭하면 우측에 하위 타입 목록이 나타납니다.
- 특정 타입만 다른 작업 세트로 지정하고 싶다면, 우측 그리드의 **`타입별 변경 작업세트`** 드롭다운에서 원하는 작업 세트를 개별 선택합니다. (패밀리 전체 설정보다 개별 설정이 우선 적용됩니다.)

---

## 3. 적용 및 실행 취소 (Undo)

1. 하단 상태 표시줄에서 변경 예정인 패밀리/타입/인스턴스 수량을 확인합니다.
2. **[적용]** 버튼을 클릭하면 최종 확인 대화상자가 표시된 후 모델에 반영됩니다.
3. 모델 변경은 **단 1개의 트랜잭션**으로 처리되므로, 변경 후 Revit에서 **`Ctrl + Z` (실행 취소)**를 1회 누르면 모든 변경 사항이 즉시 이전 상태로 안전하게 롤백됩니다.
